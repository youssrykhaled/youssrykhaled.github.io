# Yousry Mohamady

Static academic profile for GitHub Pages. The site uses standard HTML and CSS and requires no build step.

To preview locally, open `index.html` or run `python -m http.server 8000` from this directory. On GitHub, use Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)`.

The public CV is stored at `assets/Yousry_Mohamady_CV.pdf`. Replace that file with the current public version when updating the site.
